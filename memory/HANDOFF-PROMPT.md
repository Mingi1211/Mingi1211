# 다른 대화의 기억을 가져오는 프롬프트

Claude는 **다른 대화 세션을 읽을 수 없다.** 그 대화로 직접 가서 아래를 붙여넣으면 된다.

---

## A. Claude Code 세션일 때 — 직접 커밋시키기

```
이 대화에서 한 작업을 내 기억 저장소에 남겨줘.
저장소: https://github.com/Mingi1211/Mingi1211

1. 이 레포를 세션에 추가(add_repo)하고 클론
2. memory/STATE.md 와 .claude/skills/mingi-loop/SKILL.md 를 읽고 그 규칙을 따를 것
3. 이 대화의 내용을 memory/projects/<주제이름>.md 로 정리
   - 무엇을 했는지 / 왜 그렇게 정했는지 / 막힌 것 / 다음 액션
   - 추측은 [미확인] 표시. 확정 사실·결정은 memory/LEDGER.md 에 한 줄씩 추가
4. STATE.md 의 "진행 중인 것"과 "다음 액션"도 갱신
5. main 에 커밋·푸시
```

## B. 일반 대화(파일 접근 없음)일 때 — 요약만 받아오기

```
이 대화 내용을 다른 세션에 인수인계할 수 있게 마크다운으로 정리해줘. 아래 항목만, 간결하게.

## 무엇을 했나
## 왜 그렇게 정했나 (결정과 근거)
## 확정된 사실
## 막힌 것 / 열린 질문
## 다음 액션 (주체 명시)
## 재사용할 노하우

추측은 [미확인] 으로 표시할 것.
```

→ 출력된 걸 복사해서, 기억 저장소를 붙인 세션에 주고 **"이거 memory/projects/ 에 정리해서 커밋해줘"** 라고 하면 된다.

```
기억 갱신해줘
```
