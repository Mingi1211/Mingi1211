| 안 | 탈락 사유 |
|---|---|
| 자연어 로봇 동작 시뮬레이터 (VLA 웹 데모) | **전공 심화 과다.** 비로봇 전공 팀원 참여 폭이 좁음 |
| 캠퍼스 공간·장비 통합 예약 | **학교 DB·행정 권한 의존.** "학교가 안 주면?" 한 방에 무너짐 |
| 졸업요건 자가진단 | **KLAS에 졸업심사 기능이 이미 있음** + 졸업은 학교 직접 문의로 확정해야 할 민감 사안 |
| 팀플 시간표 매칭 | when2meet 등과 정면 충돌 |
| 학기 부담도 (초기안) | 방향은 채택. 단 아래 3개 수정을 거쳐 현재 형태가 됨 |

**현재 형태로 수렴시킨 3가지 수정 (사용자 요구)**
1. 개인 일정 입력·캘린더 연동 **제거** → 개인정보 0. 대신 시간표 후 "상세보기"에서 주차별 브리핑
2. 100점 점수 **화면에서 제거** → 백엔드 임계치로만. 진짜 용도는 "뺄 과목 역산"
3. 날씨 비유 **UI에서 제거** → 신선하지 않음. 캐릭터 반응 5단계 + **팔 내리기 GIF**가 등급의 얼굴

## 이 프로젝트의 핵심 논리 (잊으면 처음부터 다시 설명해야 함)

- **"난이도 판정"이 아니라 "부담 예보"** — 예보는 원래 확률이므로 데이터 불확실성이 결함이 아니라 전제가 된다
- **교수가 바뀌어도 살아남는 신호만 쓴다** — 부담의 *형태*(시험형/과제형/프로젝트형)와 *시점*. 과제 개수·시험 난도는 안 쓴다
- **파는 것은 개별 과목의 정답이 아니라 조합의 구조적 위험** — "프로젝트형 3과목 동시는 위험"은 교수가 누구든 성립
- **재미가 곧 기능** — 팔 내리는 동작이 그대로 "이 과목 빼세요" 추천을 가리킨다. 장식이 아님
- **세 가지 0** — 학교 권한 0 / 개인정보 0 / 교수 평가 0. 이게 발표 방어의 축
