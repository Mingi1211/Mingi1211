## AhaRobot 사실 (arXiv 2503.10070 v2, 문서) — 주제 설계의 전제

- 차동구동 베이스(BLDC 2 + 캐스터, ODrive) · 벨트 리프트 2축(스테퍼 DM542, 1250 mm, 탈조 시 재원점) · 양팔은 **STS3215 위치 서보**, 어깨·팔꿈치 듀얼모터(백래시 바이어스·디더링 마찰보상) · ESP32 **66 Hz** PID · 카메라 3 · ROS 2 Humble · LeRobot ACT / π0
- **힘·토크 센서 없음, 전류/토크 모드 언급 없음** → 토크 레벨 WBC 불가, **속도·위치 레벨(운동학) WBC**가 현실적
- **베이스-팔 협조 제어기 없음** — 페달 모드 전환(주행 모드 ↔ 조작 모드), "주행 중 그리퍼 위치 잠금"뿐
- 논문이 밝힌 한계: 51 kg·**충돌 감지 없음**, 원격조종 지연, Table Cleaning·Pan Sweeping에서 **액션 청크 불연속**, 베이스 속도 정책은 출발 실패 → 위치 명령으로 바꿈, 가벼운 컵 넘어뜨림
- 성공률(10회): Box Transfer 10/10 · Pen Insertion 6 · Floor-to-table 7 · Can Pressing 6 · Table Cleaning 7 · Pan Sweeping 5
- [미확인] 팔당 자유도(표에는 전체 16 DoF, 서보는 팔당 12개)

## 제안한 후보 (추천 순)

| # | 가칭 | 출발 논문 → 개선점 | 적용 소재 |
|---|---|---|---|
| A | **전신 액션 청크 후처리 최적화** (Whole-body LiPo) | LiPo(박수한 교수님)는 고정 베이스 단일 팔·관절공간. → 베이스(비홀로노믹)·리프트(스테퍼 탈조 한계)·양팔 이기종 액션으로 확장, 전신 자코비안 기반 말단 오차 상한, 접촉 구간 인지 블렌딩(LiPo 향후 과제) | 식당 테이블 정리(AhaRobot Table Cleaning의 불연속 문제 그대로) |
| B | **말단 목표 → 베이스·리프트·팔 자동 분배 QP** (운동학 WBC) | AhaRobot은 베이스·팔 분리 조종 / X-OP은 MPC라 무겁고 RB-Y1 기준 / Sentis-Khatib 우선순위 구조. → 비홀로노믹 제약 포함 우선순위 미분 IK QP로 손 목표만 주면 베이스·리프트가 따라옴 | 바닥→선반 정리(편의점 진열·돌봄), 원격조종 모드 전환 제거 |
| C | **센서 없는 접촉 감지·순응**(서보 부하/위치 오차 기반) | AhaRobot "충돌 감지 없음", OSF 운동·힘 통합, SNU-Avatar 개루프 힘 편향. → 서보 부하 레지스터+모델로 외력 추정 → 충돌 정지·법선 방향 어드미턴스 | 테이블 닦기(와이핑) — 리스크 큼, 게이트 필요 |
