# 참빛설계학기(로봇연구실인턴십) — AlohaMini 트레이 서빙·정리 로봇

## 무엇을

**2026-2 로봇특성화대학 로봇인턴십(참빛설계학기 비교과형, 일반선택 2학점 P/NP)** 계획서 작성과 플랫폼 조사.

- 팀: **어재혁(팀장·통합, 인지 겸임) / 김민기(제어, WBC) / 신원석(내비게이션, SLAM)**.
  원래 인지(VLA) 담당 1명이 있었으나 **이번 학기 불참** → 3인
- 로봇: **AlohaMini(LeRobot)** — 오픈소스 양팔 모바일 매니퓰레이터(옴니휠 3개 + 리프트 + 팔 2개)
- 과제: 1인 청년식당·요시노야식 정식집·휴게소 식당에서 **트레이를 양팔로 잡아 테이블에 놓고, 식사 후 회수**.
  기존 서빙로봇은 운반만 하고 내려놓기·회수는 사람이 함 → 그 차이가 문제정의.
  뷔페 완전 대체는 **다음 학기 캡스톤**으로 미룸(사람 많아 SLAM이 어려움)

## 계획서에 넣은 것 (v2, 서식 2~7번 · 1번 인적사항은 미작성)

- 조건: 5 m × 4 m 모의 식당, 테이블 3개, 트레이(약 200 g) 포함 **600 g 이하**, 국그릇 물 150 mL, 트레이 위치 ±5 cm·±10°
- 정량 목표: 전 과정 성공률 70%(10회) · 서빙 1회 3분 이내 / 주행 ±10 cm·±5°·도달 90%(20회) /
  파지 데이터 50 에피소드·파지 성공률 80% / 트레이 기울기 ±5°·흘림 0회·배치 ±3 cm·그리퍼 간격 ±1 cm
- 기술: ROS 2 + 상태머신 / 2D LiDAR + slam_toolbox + Nav2 + AprilTag / LeRobot ACT / QP whole-body IK + MuJoCo
- 13주 계획 9/21~12/18, **총 63시간** (안내자료 하반기 기준 40시간 이상 충족:
  OT 1 · 계획 2 · 선행연구 5 · 프로젝트 ≥20 · 지도교수 미팅 5 · 활동일지 4 · 중간 1 · 최종 2)
- 지원동기의 개인 경험(1인 덮밥집·휴게소 알바)은 **사용자 요청으로 지어낸 내용** — 실제에 맞게 고쳐야 함

## 왜 (결정과 근거)

- **인지 범위 축소** — 인지 담당 없이 3과제×50 에피소드 + 두 모델 비교 + 식사완료 인식은 2개월에 무리.
  → 학습은 **트레이 파지 1과제(ACT)**, 배치·반납은 전신 제어, 식사 완료는 **테이블 번호 입력(웹 UI)** 으로 대체
- ACT 우선 — 학습 빠르고 양팔 작업 검증됨. SmolVLA는 여건 되면 추가
- 무게 600 g — AlohaMini **1은 팔 부하 0.3 kg**(한계), **2는 1 kg**(여유). 사용 버전 미정이라 보수적으로 잡음

## 기간 추정

- 부품 도착: 10/6 주문 시 **2~3주, 최대 4주** (국경절 직후, STS3095 국내 판매처 없음) — 판매처 재고 미확인 추정치
- 3D 출력: repo 기준 약 6 kg → **80~120 프린터시간** (STL 부피 계산상 6벽이면 더 나올 수 있음)
- 조립: 부품·출력물 준비 후 **1~2주**(팔 4개 1.5~2일, 에폭시 경화 2~3일, SW·캘리브 2~3일). 조립 팔 쓰면 약 1주
- repo의 "120분 조립"은 **팔이 이미 조립된 상태의 베이스만** 기준
- → 실로봇 사용 가능은 **빨라야 10월 말~11월 초**. 계획서는 10월 2주차부터 실로봇 사용으로 짜여 있어 **안 맞음**
