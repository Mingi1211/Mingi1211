## 성격

연구 프로젝트가 아니라 **환경·도구 숙달용 실습 기록**. 파일 15개.
README: "광운대 로봇학부 / Ubuntu 24.04 + VS Code Remote-SSH 환경"

## 구성

| 파일 | 목적 |
|---|---|
| `plot_test.py` | matplotlib 그래프 저장 |
| `log_test.py` | CSV 로깅 |
| `train.py` | **tmux 세션 테스트용 장시간 작업** |
| `debug_test.py` | 디버깅 연습 |
| `robot-project/` | **uv 워크스페이스 멤버** (numpy, opencv) |

실행: `uv run python plot_test.py`

## 읽어낼 수 있는 것

원격 서버 작업 루틴(Remote-SSH + tmux 장시간 작업 + uv 워크스페이스)을 익히는 단계였다.
`readings = [0.9, 1.1, 1.0, 0.95, 1.py` 같은 **깨진 파일명**이 하나 있다 — 실습 중 실수로 생긴 듯.
