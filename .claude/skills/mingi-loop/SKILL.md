# mingi-loop — 기억 인수인계 운영 매뉴얼

목적: **매 세션을 1일차 신입으로 시작하지 않는 것.**
Claude Code 세션은 끝나면 컨텍스트가 사라진다. 사라지지 않는 것은 **레포에 커밋된 파일뿐이다.**
따라서 기억은 "기억하기"가 아니라 **"쓰기"로 구현한다.**

## 파일 역할 — 무엇을 어디에 쓰는가

| 파일 | 담는 것 | 수명 | 갱신 방식 |
|---|---|---|---|
| `CLAUDE.md` | 부트스트랩 지시. 매 턴 로드됨 | 거의 안 바뀜 | 구조가 바뀔 때만 |
| `memory/STATE.md` | **지금 뭐 하는 중인지.** 다음 액션, 열린 질문, 반려 이력 | 계속 바뀜 | **덮어쓰기** |
| `memory/LEDGER.md` | 확정된 사실·결정과 그 근거 | 영구 | **덧붙이기만** |
| `memory/PROFILE.md` | 사용자 고정 정보, 톤, 작업 스타일 | 가끔 | 새 사실 발견 시 |
| `.claude/skills/*/SKILL.md` | **재사용 가능한 방법론·환경 제약** | 영구 | 노하우 추가 시 |

**판단 기준 한 줄**
- 이번 프로젝트에서만 의미 있다 → `STATE.md`
- 다음 프로젝트에서도 쓸 수 있다 → `SKILL.md`
- "그때 왜 그렇게 정했더라?"의 답이 된다 → `LEDGER.md`

## 세션 시작 절차

1. `memory/STATE.md` 읽기 — 진행 중 작업·다음 액션·**반려 이력** 확인
2. 반려 이력에 있는 안을 **다시 제안하지 않는다.** 같은 논의를 반복하는 게 가장 큰 낭비다
3. 작업 종류에 맞는 스킬 호출 (`project-ideation` / `deck-factory`)
4. 사용자가 이전 작업을 언급하면 `LEDGER.md`를 grep 한다. 추측해서 답하지 않는다

## 세션 종료 절차 — 이게 전부다

의미 있는 작업을 했다면 **커밋과 같은 턴에** 처리한다. 나중에 하겠다는 건 안 하겠다는 뜻이다.

```
[ ] STATE.md — 진행 상황·다음 액션·열린 질문 갱신. 주체(사용자/팀/Claude)를 반드시 명시
[ ] LEDGER.md — 확정 사실·결정이 생겼으면 한 줄 추가 (근거 포함)
[ ] SKILL.md — 다음에도 쓸 노하우·환경 제약을 알아냈으면 반영
[ ] 반려된 안이 있으면 STATE.md 반려 이력에 사유와 함께 추가
```

**갱신 품질 기준**
- "덱 작업함" ❌ → "덱 10장 제작, `docs/deck/학기예보.pptx`, PR 없음, GIF 제작 여부 사용자 답변 대기" ✅
- 다음 세션의 Claude가 **파일을 열어보지 않고도 상황을 파악**할 수 있어야 한다

## 무결성 규칙

- **추측을 사실로 적지 않는다.** 미확인은 `[미확인]` 태그를 붙이고 LEDGER 하단 미확인 표에도 넣는다
- WebSearch 스니펫 기반 정보는 `근거` 칸에 그렇게 적는다. 1차 확인과 구분되어야 한다
- LEDGER는 고치지 않는다. 사실이 바뀌면 `[정정]` 새 줄
- 비밀번호·토큰·타인의 개인정보는 쓰지 않는다

## 이 시스템이 고장나는 방식 (알고 있을 것)

| 고장 | 증상 | 예방 |
|---|---|---|
| 갱신을 안 함 | STATE.md 날짜가 몇 주 전 | 커밋과 같은 턴에 갱신. 별도 작업으로 미루지 않기 |
| STATE.md 비대화 | 다 읽는 데 오래 걸림 | 끝난 건 "완료된 작업" 한 줄로 압축 |
| 다른 레포에서 안 읽힘 | 새 세션이 아무것도 모름 | `memory/BOOTSTRAP.md` 절차 수행 — **자동이 아니다** |
| 스킬이 안 불림 | 매뉴얼이 있는데 안 씀 | `description`에 사용자가 실제로 쓸 표현을 넣기 |

## 새 스킬을 만들어야 할 때

같은 작업을 **두 번째로 하고 있다면** 스킬로 만든다. 세 번째는 늦다.
`.claude/skills/<이름>/SKILL.md`에 frontmatter(`name`, `description`)를 넣고,
description에는 **사용자가 실제로 칠 법한 한국어 표현**을 포함시킨다. 그래야 로드된다.
