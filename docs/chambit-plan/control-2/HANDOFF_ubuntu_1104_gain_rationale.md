## 4. 리더–팔로워 강성 최적화 — 제안하는 정식화 (민기님 확인 필요)

정적 모델(문서 #7, 직렬 스프링, 손 하나 기준, 수평 y축). 리더 K_L, 팔로워 K_F, 오차 Δ:

- 박스 추종 비율: r = K_L / (K_L + K_F)
- 손당 내력: F_int = Δ · K_L K_F / (K_L + K_F) = Δ · r(1 − r)(K_L + K_F)
- 박스 외란 강성(양 로봇 4손 병렬): K_box = 2(K_L + K_F) → 박스 변위 = F_d / K_box

**문제**: F_int 최소화 (내력이 작을수록 박스·그리퍼에 좋음)
**제약**:
1. r ≥ r_min (리더가 경로 결정)
2. K_box ≥ F_d / e_box,max (외란에 박스가 흔들리지 않음)
3. K_F ≥ K_F,min = max( Λ_y (5.8/T_s,max)² [응답 속도, 문서 #5],  F_fric,tip/δ [실물 마찰 하한, 문서 #8 — 시뮬은 0] )
4. K_L, K_F ≤ min(F_int,max/Δ, 이산 안정 상한 #3, 토크 포화)

**풀이 방향**: S = K_L + K_F로 두면 F_int = Δ r(1−r) S. S는 제약 2로 아래가 막히고, r(1−r)은 r이 1에 가까울수록 작다
→ **팔로워는 하한 K_F,min, 리더는 제약 1·2를 만족하는 최소값**이 최적 후보. 닫힌 해를 `lf_design.py`로 계산하고 표로 남긴다.
(참고: Λ_y ≈ 3.4 kg, T_s,max 0.6 s면 K_F,min ≈ 3.4 × (5.8/0.6)² ≈ 318 N/m — 현재 300과 비슷. 이번에는 이유가 붙는다.)

**검증(시뮬 sweep)**: K_F ∈ {150, 300, 450, 600}, K_L ∈ {600, 800, 1000, 1200} 격자에서 `carry_scenario.py`(리더 5 cm 이동)를 돌려
측정 박스 추종·손 옆 힘(F_cmd,y)을 모델 예측과 비교. 11/4 측정이 예측보다 작았던 것(3.1 vs 3.6 cm, 5.3 vs 10.9 N)의 원인도 여기서 확인.
sweep은 시간이 걸리므로(RTF 0.3) 격자를 줄이거나 헤드리스로. 자동 실행 스크립트는 민기님 확인 후 작성.

z축은 별도: 두 로봇 K_z를 같게(박스 수평 유지), 값은 #4.

## 5. 이산 안정 조건 — D_safety·ω_max를 실험값 대신 유도로 (2·3번)

한 축 질량-댐퍼 Λv̇ = −Dv를 주기 T로 계산하고, 측정→명령 지연이 d스텝이면

- d = 0: v_{k+1} = (1 − DT/Λ) v_k → 안정 조건 **D < 2Λ/T** (문서 #8)
- d = 1: v_{k+1} = v_k − (DT/Λ) v_{k−1} → 특성식 z² − z + a = 0 (a = DT/Λ). Jury 조건 0 < a < 1 → **D < Λ/T = 0.5 · 2Λ/T**
  → 지금 코드의 D_safety 0.5는 "1스텝 지연"을 가정하면 정확히 나오는 값. **실측 d로 확인**하고 d가 크면 계수를 다시 계산
- K(스프링)까지 포함한 2차 이산 시스템(지연 d)의 고유값 |z| < 1 영역을 수치로 구해 ωn 경계를 얻는다 → ω_max = 여유율 × 경계

할 일: ① 루프 주기 T와 지연 d 측정(상태 메시지 시각 vs 토크 반영 시각, 노드 로그의 dt 분포) ② `stability_bound.py`로 경계 계산 ③ 코드 상수 교체 + 근거 주석
